# UPD-002 — исследование предобработки собственного BM25

Запрос: сосредоточиться на НИРС, исключить ручной подбор документов и сравнить обработку текста по Recall@5 и MRR. Актуальные поведение/проверки: REQ-027, GWT-054/055, Tech/05; результаты — V-019 и benchmark/README.md.

Реализованы одинаковые для запросов и документов профили raw/lower/stop/technical/legacy/lemma/lemma_technical; индекс и BM25 написаны самостоятельно. Сортировка задаётся оценкой, затем ID при равенстве; нет ручных документов и специальных заголовков. Лемматизация — pymorphy3 с закреплённым словарём. Параметры k1/b и тексты корпуса фиксированы.

План проверки выполнен: 12 новых авторских запросов покрывают 30 документов, минимум три релевантных документа на запрос; отдельно оценены 10 обычных вопросов КТ2. Прогнаны семь профилей и 40 тестов. Новый набор известен разработчикам, разметка требует независимого просмотра; holdout не заявляется. Рабочий профиль сервера — lemma; Docker/деплой устанавливают зависимости, эксперимент не требует LLM и не меняет промпт.
