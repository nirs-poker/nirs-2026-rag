# 04. API и доступ

> План. В макете сервера нет.

## Доступ

- Все адреса `/api/*`, кроме регистрации и входа, требуют вошедшего пользователя (`REQ-002`). Без входа - ответ `401`, клиент переводит на страницу входа.
- Сессия - cookie `HttpOnly` после входа.
- Пользователь видит и меняет только свои раздачи (`R-011`); чужая раздача - `404`.

## Адреса

| Метод и адрес | Назначение | Требования |
|---|---|---|
| `POST /api/auth/register` | Регистрация | REQ-001 |
| `POST /api/auth/login` | Вход | REQ-001 |
| `POST /api/auth/logout` | Выход | REQ-002 |
| `GET /api/me` | Текущий пользователь (имя, email, уровень) | - |
| `GET /api/hands` | История раздач пользователя | REQ-003 |
| `POST /api/hands` | Новая раздача | REQ-004 |
| `GET /api/hands/{id}` | Раздача: сообщения и последняя ситуация | REQ-003, REQ-009 |
| `POST /api/hands/{id}/messages` | Задать вопрос (теория или раздача), получить ответ | REQ-005 ... REQ-018 |

`hands` - это переписки в истории; в одной переписке могут быть и вопросы по теории, и разбор раздачи.

## Вопрос и ответ

Запрос:
```json
{ "text": "Играем один на один, стеки по 100 ББ. Соперник на баттоне поднял до 2.5 ББ, у меня на большом блайнде туз-король разной масти. Что делать?" }
```

Ответ на теорию (`kind: theory`), например на "Что такое колл?":
```json
{
  "status": "ok",
  "kind": "theory",
  "answer": {
    "topic": "Колл",
    "explanation": "Колл - это когда вы доплачиваете ставку соперника и остаётесь в раздаче...",
    "example": "Соперник поставил 2 ББ, вы доплачиваете 2 ББ и смотрите следующую карту.",
    "tags": ["Чек", "Рейз", "Фолд"],
    "fragment_ids": ["glossary-call"]
  }
}
```

Ответ на раздачу (`kind: hand`):
```json
{
  "status": "ok",
  "kind": "hand",
  "answer": {
    "action": "3-бет", "size_bb": 10,
    "tags": ["AKo - сильный бродвей", "BB против баттона", "Стек 100 ББ"],
    "explanation": "...",
    "fragment_ids": ["hu-bb-vs-btn-open", "concept-position"]
  },
  "situation": {
    "hero_cards": ["As", "Kd"], "hero_position": "BB",
    "villain_position": "BTN", "stack_bb": 100,
    "actions": [{"street": "preflop", "position": "BTN", "action": "рейз", "size_bb": 2.5}],
    "board": [], "pot_bb": 3.5, "to_call_bb": 1.5
  },
  "math": { "pot_odds_pct": 30 }
}
```

Другие статусы:

| status | Когда | Что в ответе |
|---|---|---|
| `clarify` | Вопрос о раздаче, но не хватает данных (`REQ-011`) | `missing`: список недостающих полей, текст-вопрос |
| `no_sources` | Нет фрагментов выше порога (`REQ-012`) | Текст пояснения, без `action` |
| `off_topic` | Вопрос не о покере (`REQ-016`) | Текст отказа |
| `error` | Ошибка LLM (`REQ-013`), код ответа `502` | Текст ошибки; вопрос сохранён, можно повторить |
