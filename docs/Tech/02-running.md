# 02. Запуск и настройки

## Макет (сейчас)

Макет - статичные HTML-страницы, установка не нужна.

**Способ 1.** Открыть в браузере `code/client/login.html` двойным кликом. Дальше переходить по ссылкам: вход -> чат -> "Выйти" -> вход.

**Способ 2** (если браузер не подгружает стили, картинки или шрифт с локального диска):

```bash
cd code/client
python -m http.server 8000
```

Открыть `http://localhost:8000/login.html`. Остановить сервер - Ctrl+C.

**Поддержка браузеров.** Появление кнопки "К столу" по прокрутке использует CSS scroll-driven animations (Chrome, Edge, свежий Safari). В браузерах без поддержки кнопка видна всегда и работает так же.

## Приложение (план)

Цель - запуск одной командой.

```bash
cp .env.example .env      # вписать ключ API LLM
pip install -r requirements.txt
python -m code.server     # точная команда появится вместе с сервером
```

## Настройки (план, файл `.env`)

| Переменная | Смысл | Пример |
|---|---|---|
| `LLM_BASE_URL` | Адрес API провайдера | `https://api.example.com/v1` |
| `LLM_API_KEY` | Ключ API | не коммитится |
| `LLM_MODEL` | Имя модели | зависит от провайдера |
| `RETRIEVAL_TOP_K` | Сколько фрагментов передавать в LLM | `5` |
| `RETRIEVAL_MIN_SCORE` | Порог релевантности `R-006` | подбирается на benchmark |
| `DATABASE_PATH` | Путь к файлу базы | `data/app.sqlite3` |

`.env` в репозиторий не коммитится; в репозитории будет `.env.example` с пустыми значениями.
