# Product - что строим

| Файл | Для чего |
|---|---|
| [01-context.md](01-context.md) | Цель, ценность, границы первой версии, ограничения |
| [02-users-and-scenarios.md](02-users-and-scenarios.md) | Роли пользователей, основной и дополнительные сценарии |
| [03-requirements.md](03-requirements.md) | Требования `REQ-*` и проверки к ним в формате Given/When/Then `GWT-*` |
| [04-interface-and-behavior.md](04-interface-and-behavior.md) | Экраны, элементы, действия, состояния и валидации |
| [05-rules-and-data-meaning.md](05-rules-and-data-meaning.md) | Термины, смысл данных, правила `R-*`, требования к источникам корпуса |

Порядок чтения: 01 -> 02 -> 03, затем 04 и 05 по необходимости. По `03-requirements.md` принимают работу и пишут тесты.
