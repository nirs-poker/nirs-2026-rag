# 04. Интерфейс и поведение

Описывает, где пользователь что видит, какие данные и действия есть на каждом экране. Макет: `code/client/` (статичный).

## Экраны

| Экран | Файл макета | Кому доступен |
|---|---|---|
| Вход | `code/client/login.html` | Гость |
| Регистрация | `code/client/register.html` | Гость |
| Чат | `code/client/prototype.html` | Пользователь |

Общий стиль: казино. Тёмно-бордовый ковёр с золотым узором, зелёное сукно стола, золотые акценты, заголовки шрифтом Old Standard TT.

## Вход

**Данные:** email, пароль, "Запомнить меня".
**Действия:** "Войти" -> чат; "Зарегистрироваться" -> регистрация; "Забыли пароль?" (в первой версии - заглушка).
**Валидации:** оба поля обязательны; при неверных данных - сообщение "Неверный email или пароль" (`GWT-004`).

## Регистрация

**Данные:** имя или ник, email, пароль, повтор пароля, уровень игры (только начинаю / знаю правила / играю регулярно), согласие "сервис - тренажёр, не для реальной игры".
**Действия:** "Создать аккаунт" -> чат; "Войти" -> вход.
**Валидации:** все поля обязательны; email в правильном формате; пароль не короче 8 символов (`R-010`); пароли совпадают; согласие отмечено (`GWT-002`, `GWT-003`).
**Смысл уровня игры:** влияет на подробность объяснений (подробнее для начинающих).

## Чат

### Левая панель
- Логотип "Покерный тренер".
- Кнопка **"+ Новая раздача"** (`REQ-004`).
- **История раздач** (`REQ-003`): группы "Сегодня", "Вчера", "Ранее"; у пункта - мини-карты руки (или "?" для теоретического вопроса), название и итоговое решение; текущая раздача подсвечена.
- **Профиль:** аватар с первой буквой имени, имя, email, кнопка "Выйти" (`GWT-006`).

### Шапка
Название текущей раздачи.

### Стол (`REQ-009`)
Стоит в начале ленты и прокручивается вместе с ней. Заполняется только вопросами о раздаче; при вопросах по теории остаётся пустым или без изменений.

| Элемент | Где | Что показывает |
|---|---|---|
| Дилер | сверху по центру | фигурка дилера |
| Вы | снизу слева | аватар аккаунта, позиция, стек; перед местом - ваши карты |
| Соперник | снизу справа | фигурка, позиция, последнее действие; перед местом - рубашки карт, ставка, кнопка дилера "D" |
| Банк | на сукне под дилером | размер банка в ББ |
| Улицы | центр сукна | слоты: флоп (3), тёрн (1), ривер (1); заполняются по мере описания раздачи |

### Лента сообщений
- **Вопрос пользователя:** справа, светло-зелёный пузырь с золотым контуром.
- **Ответ** - слева, тёмно-зелёный пузырь. Два вида:
  - **на раздачу** (`REQ-006`): фишка, подпись "Рекомендация", действие крупно золотым шрифтом, теги ситуации, объяснение;
  - **на теорию** (`REQ-017`): фишка, подпись "Объяснение", термин или тема крупно золотым шрифтом, определение простым языком, пример, связанные термины тегами.
- Низ ленты плавно затухает перед полем ввода.

### Кнопка "К столу" (`REQ-010`)
Появляется по центру над полем ввода, когда стол ушёл из вида; по нажатию лента плавно прокручивается к столу.

### Поле ввода
Строка с золотой окантовкой, подсказка "Опишите раздачу: ваши карты, позиция, действия соперника...", кнопка **"Спросить"** (`REQ-005`).

## Состояния чата

| Состояние | Что видит пользователь |
|---|---|
| Новая переписка | Пустой стол, подсказки с примерами вопросов обоих видов ("Что такое колл?", "У меня AKo на BB, соперник поднял до 2.5 ББ...") |
| Ожидание ответа | Вопрос в ленте, на месте ответа - индикатор загрузки, кнопка "Спросить" недоступна |
| Ответ получен | Ответ в ленте, стол обновлён |
| Нужно уточнение (`REQ-011`) | Ответ-вопрос: что именно нужно дописать |
| Нет материалов (`REQ-012`) | "Уверенного совета нет" с пояснением, без действия |
| Ошибка (`REQ-013`) | Сообщение об ошибке и кнопка "Отправить ещё раз" |
