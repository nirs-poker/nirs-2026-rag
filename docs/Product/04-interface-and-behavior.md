# 04. Интерфейс и поведение

Описывает, где пользователь что видит, какие данные и действия есть на каждом экране. Макет: `code/client/` (статичный).

## Экраны

| Экран | Файл макета | Кому доступен |
|---|---|---|
| Вход | `code/client/login.html` | Гость |
| Регистрация | `code/client/register.html` | Гость |
| Чат | `code/client/prototype.html` | Пользователь |

Общий стиль: казино. Тёмно-бордовый ковёр с золотым узором, зелёное сукно стола, золотые акценты, заголовки шрифтом Old Standard TT.

## Вход

**Данные:** email, пароль, "Запомнить меня".
**Действия:** "Войти" -> чат; "Зарегистрироваться" -> регистрация; "Забыли пароль?" (в первой версии - заглушка).
**Валидации:** оба поля обязательны; при неверных данных - сообщение "Неверный email или пароль" (`GWT-004`).

## Регистрация

Имя, email, пароль, повтор пароля и согласие с тем, что сервис — тренажёр. Проверки полей описаны в REQ-001.

## Чат

| Область | Содержимое и действия |
|---|---|
| Слева | Все чаты пользователя. После первого ответа приложение даёт чату название простыми словами без сокращений, например «Туз-король на большом блайнде». Чат можно переименовать или удалить. |
| Справа | Все раздачи текущего чата. У каждой видны карты пользователя, текущая улица и банк. Нажатие открывает её стол. При возврате в чат открывается последняя использованная раздача. Отдельного удаления раздачи нет. |
| В начале ленты | Стол появляется с первой раздачей и уходит вверх при прокрутке. Показывает карты, позиции, действия, улицу и банк на выбранном ходу. |
| Под столом | «Назад» и «Вперёд» перемещают на один ход любого игрока. Рядом цветная точка для каждого хода пользователя по R-018. «К сообщению» ведёт к последнему сообщению этой раздачи. Кружок на кнопке показывает число её непрочитанных ответов. |
| Ввод | Текст относится к раздаче на столе. Для явно другой ситуации приложение предлагает начать новую раздачу. «Добавить стол» открывает выбор карт, позиций и ходов. «Решить» отправляет ситуацию. Теми же элементами можно поправить распознанные данные. |
| Настройки | При включённой подсветке нажатие на покерный термин в ответе открывает короткое определение. |
| Низ страницы | Общая подпись «Ответы генерирует ИИ, и они могут содержать ошибки». |

Внизу ленты экран следует за печатающимся ответом. При просмотре стола экран сохраняет положение, стол показывает новый ход, а счётчик сообщает об ответе. При начале новой раздачи лента переходит к ней. Сообщения и непрочитанные ответы относятся к своей раздаче. Теоретические сообщения до первой раздачи остаются в чате.

Это целевое поведение. Статичный макет в `code/client/` показывает более ранний вариант интерфейса.
