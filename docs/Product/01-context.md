# 01. Контекст: цель и границы

## Назначение документа

Описывает, зачем нужен продукт, кому он полезен и что входит в первую версию. Документ для любого участника и преподавателя: читается без технической подготовки.

## Кратко

**Покерный тренер** - веб-приложение для обучения Техасскому Холдему. Пользователь задаёт вопрос обычным текстом и получает ответ на понятном языке. Можно спросить:

- **теорию** - что значит термин, как устроены правила, что такое концепция ("что такое колл?", "что такое ривер?", "как считать шансы банка?");
- **разбор раздачи** - описать ситуацию за столом и получить рекомендацию, как лучше сыграть.

Ответ строится по материалам корпуса (правила, термины, стратегия): приложение находит подходящие фрагменты (поиск BM25), для раздачи считает математику и просит языковую модель (LLM) сформулировать объяснение или совет.

## Задача пользователя

Новичку непонятны термины и правила, а учебные материалы по покеру объёмные и написаны в общем виде. Хочется быстро спросить "что такое 3-бет" и получить короткий понятный ответ с примером, а не листать статьи. Игроку посильнее нужен ответ на свою конкретную ситуацию: "у меня такие карты, соперник сделал так-то, что делать?". Найти нужное место в книге долго, а таблицы стратегий без объяснений не учат думать.

Продукт отвечает на оба вида вопросов за секунды и объясняет причину, чтобы человек понимал логику, а не заучивал.

## Ценность

- Быстрые понятные ответы на вопросы по правилам и терминам - путь от новичка к уверенной игре.
- Быстрый разбор своих раздач после игры.
- Объяснение "почему", а не только "что делать".
- История разборов сохраняется, к ней можно вернуться.
- Проверяемое качество: ответы сверяются с собственным набором раздач с известным правильным решением (benchmark).

## Основные сущности

| Сущность | Смысл |
|---|---|
| Пользователь | Зарегистрированный игрок; у него свой аккаунт и своя история |
| Раздача (чат) | Отдельная переписка о конкретной ситуации; показывается в истории слева |
| Вопрос | Сообщение пользователя: вопрос по теории или описание раздачи |
| Ответ | Для теории - объяснение с примером; для раздачи - рекомендуемое действие, объяснение и теги ситуации |
| Ситуация за столом | Разобранные из вопроса карты, позиции, ставки и банк; показываются на столе |
| Корпус | Набор материалов (правила, термины, стратегия), по которым ищутся фрагменты для ответа |

## Что входит в первую версию

- Техасский Холдем, No-Limit, **игра один на один** (heads-up), кэш-игра, стеки до 100 ББ.
- Вопросы свободным текстом на русском языке.
- **Вопросы по теории:** термины (колл, рейз, 3-бет, ривер, баттон...), правила игры (порядок ходов, улицы, комбинации и их старшинство), базовые понятия стратегии (позиция, шансы банка, ауты).
- **Разбор раздач, префлоп** - основной объём разборов: решения до открытия общих карт.
- **Разбор раздач после флопа** - базовые случаи: дро, ауты, шансы банка.
- Benchmark из двух частей: теоретические вопросы и раздачи (в основном префлоп).
- Регистрация, вход, личная история раздач.
- Показ ситуации на столе над перепиской.

## Что не входит

- Игра больше чем на двоих, турниры (ICM), другие виды покера (Омаха и др.).
- Использование во время реальной игры, интеграция с покер-румами, игра на деньги.
- Загрузка истории раздач из файлов покер-румов.
- Точные решения уровня солвера (GTO) для сложных ситуаций после флопа.
- Публичный хостинг: приложение запускается локально.

## Ограничения

- Корпус собирается только из материалов с открытой лицензией и собственных конспектов команды (платные книги и курсы использовать нельзя).
- Языковая модель вызывается по API внешнего провайдера, своя модель не разворачивается.
- Математику (шансы банка, ауты) считает код, а не языковая модель.
- Продукт - тренажёр. Ответы носят обучающий характер.

## Общая логика работы

1. Пользователь входит в аккаунт и открывает новую раздачу или старую из истории.
2. Пишет вопрос: по теории или с описанием раздачи.
3. Приложение определяет вид вопроса.
4. Для теории: ищет в корпусе фрагменты по правилам и терминам, языковая модель формулирует объяснение с примером.
5. Для раздачи: разбирает ситуацию и показывает её на столе, ищет фрагменты по стратегии, считает математику; языковая модель формулирует ответ - действие, объяснение, теги.
6. Ответ появляется в ленте, переписка сохраняется в истории.
