## V-006 — 2026-11-20 — конфигурация Groq для RAG КТ2

- **Что:** настройка Groq по умолчанию, чтение ключа и сохранение безопасного контракта ответа RAG.
- **Как:** `python -X utf8 -m unittest discover -s code/tests -v`; ключ API в окружение проверки не передавался.
- **Результат:** 9 из 9 тестов пройдены. Подтверждены базовый адрес `https://api.groq.com/openai/v1`, модель `openai/gpt-oss-20b`, чтение `GROQ_API_KEY` и его приоритет над общим `LLM_API_KEY`. Запрос задаёт `reasoning_effort=low` и лимит 700 токенов. Ошибка аутентификации Groq выводится без значения ключа. Сквозной вызов и метрики ответов не запускались: в окружении нет ключа.
- **Дополнительная проверка:** 10 из 10 тестов пройдены после добавления описательного `User-Agent: nirs-poker-trainer/1.0`. HTTP 403 отделён от ошибки ключа HTTP 401. Пользователь подтвердил успешный вызов через curl и блокировку Python-клиента с кодом 1010; повторный сквозной вызов после изменения заголовка ещё не подтверждён.
- **Связано:** D-016, REQ-007, REQ-013, REQ-015.
