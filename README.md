# Покерный тренер

Учебный проект НИРС 2026 по безлимитному техасскому холдему. На КТ2 работает веб-чат по теории покера. Например, на вопрос «Чем сет отличается от трипса?» поиск BM25 подбирает фрагменты теории, а модель Groq формулирует ответ. В чате можно раскрыть источники и прочитать использованные фрагменты. Если сведений недостаточно, тренер сообщает об этом.

## Как запустить чат-бота

Нужны Python 3.11+ и Node.js 22.12+ из ветки 22 либо Node.js 24+. Команды ниже выполняются из корня проекта.

1. Если файла `.env` ещё нет, скопируйте `.env.example` в `.env` и укажите в нём свой `GROQ_API_KEY`. На macOS и Linux используйте `cp .env.example .env`, в Windows PowerShell — `Copy-Item .env.example .env`.
2. В первом терминале запустите Python-сервер:

   ```bash
   python3 -X utf8 code/server/web.py
   ```

   В Windows используйте `python` вместо `python3`.
3. Во втором терминале запустите фронтенд:

   ```bash
   cd code/client
   npm ci
   npm run dev
   ```

   `npm ci` нужен при первом запуске и после обновления зависимостей.
4. Оставьте оба терминала открытыми и перейдите в браузере по ссылке [http://localhost:5176/frontend.html](http://localhost:5176/frontend.html).

Для проверки спросите «Чем сет отличается от трипса?». Источники раскрываются под ответом. Запуск готовой сборки описан в [инструкции](docs/Tech/02-running.md).

## Публикация на REG.RU

Для `nirs.ukidoshi.store` подготовлен GitHub Actions workflow: Pull Request проверяет тесты и сборку, push в `main` после успешной проверки синхронизирует сайт на REG.RU по SSH+rsync, запрашивает перезапуск Passenger и проверяет `/api/health`. Для работы нужны виртуальный хостинг с Python/CGI и Passenger, SSH-доступ и настроенные GitHub Secrets. Первоначальная настройка описана в [инструкции публикации](docs/Tech/02-running.md#публикация-на-reg-ru). До настройки доступа приложение не опубликовано.

## План развития

Следующий этап — разбор раздач и тренировка решений за столом 6-max со стартовыми стеками 100 ББ. Пользователь сможет описать ситуацию текстом или ввести её на столе, вести несколько раздач в чате и листать ходы. Для разбора планируется брать действие из подходящего решения PokerBench, рассчитывать шансы банка и ауты в коде и передавать результат модели для объяснения.

В режиме разбора оценка будет видна сразу, а в тренировке — после завершения раздачи. При отсутствии точного эталона тренер предложит рекомендацию по похожей ситуации и отметит ход серым.

[Спецификация ближайшей КТ по RAG](docs/Tech/06-rag-checkpoint.md) описывает локальный прототип по теории, 30 документов корпуса и 15 контрольных вопросов.

Качество ответов по теории проверено на контрольных вопросах с эталонами и ловушках. Разбор раздач планируется проверять на тестовой части PokerBench.

HTTP API и RAG проверены автотестами; результаты отдельных прогонов и экспериментов собраны в [отчёте](code/tests/benchmark/README.md). ## Поиск и проверка КТ2

Новые прогоны GPT-OSS 20B и 120B с одинаковым промптом v2 и фрагментами дали по 7/10 полностью правильных ответов и по 5/5 отказов. [Сравнение моделей](code/tests/benchmark/README.md#сравнение-gpt-oss-20b-и-120b-2026-11-20) содержит разбор разных ошибок и ограничения оценки. Рабочая модель автоматически не переключалась.

Уточнённая инструкция v2 применяется в рабочем клиенте. На одинаковых фрагментах её историческая строгая Accuracy составила 0,60 против 0,30 у исходной; позже свежие прогоны моделей на том же benchmark дали 0,70 у 20B и 120B. Набор небольшой, подробности и ограничения — в [сравнении промптов и моделей](code/tests/benchmark/README.md#сравнение-промптов-2026-11-20).

Команды поиска и тестов выполняются из корня репозитория:

```powershell
python -X utf8 code/server/ask.py --search-only "Кто первым действует на префлопе за столом 6-max?"
python -X utf8 code/tests/benchmark/run.py --search-only --output code/tests/benchmark/results/search.json
python -X utf8 -m unittest discover -s code/tests -v
```

JSONL уже подготовлен. Для повторной выгрузки из исходных `.doc` нужен Microsoft Word. Команда `python -X utf8 code/server/prepare_corpus.py` пересобирает корпус и вопросы по таблицам спецификации. Параметры BM25, результаты и команда сквозного прогона приведены в [отчёте бенчмарка](code/tests/benchmark/README.md).

Чат и `ask.py` также ищут по русскому глоссарию и конспектам GTO в `code/server/corpus/additional/`. Попробуйте «Чем сквиз отличается от 3-бета?» или «Что такое равновесие Нэша в покере?». Для прогона КТ2 используется исходный корпус из 30 разделов.
