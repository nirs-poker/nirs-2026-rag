# Покерный тренер

Учебный проект НИРС 2026. Веб-приложение для обучения игре в Техасский Холдем (No-Limit, один на один). Пользователь задаёт вопрос обычным текстом в чате. Вопросы бывают двух видов:

- **по теории** - термины, правила и понятия: "что такое колл?", "что такое ривер?", "чем рейз отличается от 3-бета?", "что такое шансы банка?". Приложение объясняет простым языком с примером;
- **разбор раздачи** - пользователь описывает ситуацию за столом, а приложение рекомендует действие (фолд, колл, рейз и т.д.) и объясняет, почему оно лучше.

Внутри работает RAG:
1. по тексту вопроса BM25 ищет подходящие фрагменты в корпусе материалов по правилам, терминам и стратегии;
2. для разбора раздачи математику (шансы банка, ауты) считает код;
3. LLM по найденным фрагментам (и расчётам) формирует объяснение или рекомендацию.

Качество проверяется на собственном benchmark-наборе: теоретические вопросы с известным ответом и раздачи с известным правильным решением.

## Запуск макета

Сервер не нужен. Откройте в браузере файл:

```
code/client/login.html
```

Если браузер не подгружает стили или шрифт с локального диска, запустите простой сервер из папки `code/client`:

```bash
cd code/client
python -m http.server 8000
```

и откройте `http://localhost:8000/login.html`. Подробно: [docs/Tech/02-running.md](docs/Tech/02-running.md).

## Основные сценарии

- **Вопрос по теории:** пользователь пишет "что такое колл?" -> получает понятное объяснение с примером.
- **Разбор раздачи:** пользователь пишет раздачу ("у меня AKo на большом блайнде, соперник с баттона поднял до 2.5 ББ") -> видит ситуацию на столе и ответ: рекомендуемое действие и объяснение.

Подробно: [docs/Product/02-users-and-scenarios.md](docs/Product/02-users-and-scenarios.md).
