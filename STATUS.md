# Текущее состояние

Обновлено: 2026-11-23.

## Этап

Рабочий прототип чата по покерной теории (КТ2). Разбор раздач, авторизация и серверное хранение истории не реализованы.

## Что готово

- Фронтенд на React/TypeScript, локальные чаты, просмотр источников и ручной ввод элементов стола.
- Python API `POST /api/ask` и `GET /api/health`; поиск BM25 по корпусу и запросы к Groq `openai/gpt-oss-20b`.
- Контрольный корпус КТ2 из 30 документов и отдельные дополнительные глоссарий/GTO-документы для живого чата.
- Сравнение промпта v2 на тех же фрагментах: историческая строгая Accuracy 0,60 против 0,30 у исходного. Свежие сравнения GPT-OSS 20B и 120B дали 0,70 каждой модели на 10 обычных вопросах; рабочей оставлена 20B. Оценки агента и ограничения описаны в [benchmark-отчёте](code/tests/benchmark/README.md).

## Публикация

Подготовлен GitHub Actions workflow для REG.RU: проверка тестов и сборки на Pull Request, SSH+rsync деплой после push в `main`, перезапуск Passenger и проверка `/api/health`. Изменения workflow и WSGI-адаптера находятся в ветке `infra/regru-github-actions-deploy`; приложение ещё не опубликовано. Для первого деплоя нужны услуга с Python/CGI и Passenger, SSH-ключ в панели хостинга, GitHub Environment `production`, его secrets и Groq `.env` на хостинге. Инструкция: [Tech/02-running.md](docs/Tech/02-running.md).
