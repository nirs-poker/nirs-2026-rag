# Текущее состояние

Обновлено: 2026-11-28.

## Этап

Рабочий прототип чата по покерной теории (КТ2). Разбор раздач, авторизация и серверное хранение истории не реализованы.

## Что готово

- Фронтенд на React/TypeScript, локальные чаты, просмотр источников и ручной ввод элементов стола.
- Python API `POST /api/ask` и `GET /api/health`; поиск BM25 по корпусу и интеграция с GigaChat `GigaChat-3-Ultra` (D-018); локальный сквозной запрос проверен: ответ о кикере с D13/D14.
- Контрольный корпус КТ2 из 30 документов и отдельные дополнительные глоссарий/GTO-документы для живого чата.
- Сравнение промпта v2 на тех же фрагментах: историческая строгая Accuracy 0,60 против 0,30 у исходного. Свежие сравнения GPT-OSS 20B и 120B дали 0,70 каждой модели на 10 обычных вопросах; на момент сравнения оставлена 20B; эти оценки не относятся к GigaChat. Оценки агента и ограничения описаны в [benchmark-отчёте](code/tests/benchmark/README.md).

## Публикация

GitHub Actions и Passenger/WSGI опубликованы на REG.RU (`nirs.ukidoshi.store`); по сообщению пользователя фронт и API работают, а исходящие запросы к Groq с хостинга возвращают 403. В ветке `rag/gigachat-3-ultra` подготовлен переход на GigaChat; для публикации нужны новые настройки `.env`, доступ к OAuth на порту 9443 и CA при необходимости. Инструкция: [Tech/02-running.md](docs/Tech/02-running.md).

## Локальное окружение

В ветке `infra/docker-local` подготовлен Compose с AlmaLinux 8.10, Python 3.14.6, Apache/Passenger 6.2.0 и MySQL 8.0.46 локально (на хостинге Percona 8.0.25-15) по данным хостинга, а также опциональным Vite. MySQL пока не используется приложением. Порядок первого запуска и выбор режима описаны в README. Результаты проверки — в Service/verification.

## Общие вопросы о правилах

В ветке `rag/general-poker-questions` добавлен вводный подбор для общих вопросов новичка. Четыре формулировки, включая «Что такое покер?», проверены реальными запросами GigaChat с источниками, 38 тестов прошли; контрольная выдача КТ2 сохранена (V-015). Для публикации требуется PR и деплой.

В Docker-профиле dev добавлено автоматическое перечитывание Python-кода через маркер Passenger; изменение .env требует пересоздания app. Проверка — V-016.

В дополнительный глоссарий добавлен GL25 «Постфлоп»: определение и три улицы с источником сверки, основной корпус КТ2 сохранён. Проверки — V-017.

Контекст текущей переписки и ограниченные настройки стиля реализованы без авторизации/БД (REQ-026). История/стиль передаются браузером; источником фактов остаются документы. 47 Python-тестов, три теста клиента и сборка прошли; результаты живого диалога и benchmark — V-018. Публикация изменений пока не выполнена.
